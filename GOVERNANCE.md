# Governance

skill-cli is maintainer-led. The maintainer is
[@showxu](https://github.com/showxu).

## Project Scope

The organization develops `skill`, which installs and updates agent skills,
resolved to exact versions, and maintains its Homebrew distribution tap.

## Maintainer Responsibilities

- Review and merge changes within the project scope.
- Keep repositories buildable, testable, and documented.
- Preserve documented boundaries and compatibility commitments.
- Decide when proposals are accepted.

## Decision Records

Durable decisions live in each repository's `Documentation/Decisions/`.
Architecture documentation describes the current state.
